# Calculator Frontend (React)

Фронтенд часть веб-калькулятора, разработанная на React.

## Автор
**Мерзляков Владимир** (Person 3 - Frontend Lead)

## Возможности

- ✅ Главный экран калькулятора с функциональными кнопками
- ✅ Поддержка базовых операций (сложение, вычитание, умножение, деление)
- ✅ Квадратный корень
- ✅ Многоязычность (EN/RU) с переключением
- ✅ Интеграция с Backend REST API
- ✅ Session management
- ✅ Обработка ошибок

## Технологии

- React 18.2
- Axios для HTTP запросов
- i18next для локализации
- CSS для стилей

## Установка

```bash
cd frontend
npm install
```

## Запуск

Убедитесь, что backend запущен на порту 8080, затем:

```bash
npm start
```

Приложение откроется на `http://localhost:3000`

## Переменные окружения

В файле `.env`:

```
REACT_APP_API_URL=http://localhost:8080/api
```

## API Integration

### Endpoints используемые приложением:

```
POST /api/calculator/calculate - выполнить операцию
GET  /api/calculator/operations - получить список операций
GET  /api/calculator/health - проверка работоспособности

GET    /api/history - получить историю (для будущего использования)
DELETE /api/history - очистить историю (для будущего использования)

GET /api/settings - получить настройки (для будущего использования)
PUT /api/settings - обновить настройки (для будущего использования)
```

### Session Management

Приложение автоматически генерирует уникальный Session ID при первом запуске и сохраняет его в localStorage. Этот ID передается в каждом запросе к API через заголовок `X-Session-Id`.

## Многоязычность

Приложение поддерживает английский (EN) и русский (RU) языки. Переключение языка происходит через кнопки в правом верхнем углу. Выбранный язык сохраняется в localStorage.

## Особенности реализации

### Компоненты

1. **Calculator** - главный компонент с логикой калькулятора
2. **Display** - отображение результатов и выражений
3. **Button** - переиспользуемая кнопка с вариантами стилей
4. **LanguageSwitcher** - переключатель языка

### Сервисы

Все API запросы организованы через сервисные модули:
- `calculatorService` - операции калькулятора
- `historyService` - история вычислений
- `settingsService` - настройки пользователя

### Стили

Использован чистый CSS с:
- Градиентный фон приложения
- Анимации при нажатии на кнопки
- Адаптивный дизайн
- Отдельные варианты стилей для разных типов кнопок

## Troubleshooting

### Ошибка подключения к API
- Проверьте, что backend запущен на порту 8080
- Проверьте настройки CORS на backend
- Проверьте переменную окружения REACT_APP_API_URL

### Проблемы с i18n
- Убедитесь, что все переводы добавлены в `i18n.js`
- Проверьте, что компонент обернут в Translation HOC
