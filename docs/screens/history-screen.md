# Экран "История вычислений"

## Описание
Экран отображает историю всех вычислений пользователя с возможностью просмотра, фильтрации и удаления записей.

## Компоненты

### 1. Header (Шапка)
- **Кнопка "Назад"**: возврат на главный экран
- **Заголовок**: "История" / "History"
- **Кнопка "Очистить"**: удаляет всю историю (с подтверждением)

### 2. Search Bar (Поиск)
- Текстовое поле для поиска
- Фильтрация по выражениям в реальном времени
- Иконка поиска (🔍)

### 3. History List (Список истории)
- Группировка по датам (Сегодня, Вчера, дата)
- Каждая запись содержит:
  - Время операции
  - Выражение (например: "5 + 3 = 8")
  - Название операции (локализовано)
  - Кнопка удаления [×]

### 4. Empty State
Если история пуста:
```
    📋

    История пуста

    Выполните вычисления,
    и они появятся здесь
```

### 5. Load More Button
- Кнопка для подгрузки старых записей
- Показывается только если есть еще записи

## Интерактивность

### Действия пользователя:
1. **Клик на запись** → Загружает значения в калькулятор
2. **Клик на [×]** → Удаляет конкретную запись (без подтверждения)
3. **Клик "Очистить"** → Модальное окно с подтверждением
4. **Ввод в поиск** → Фильтрация списка

### Модальное окно подтверждения очистки:
```
┌────────────────────────────────┐
│  Очистить историю?             │
│                                │
│  Это действие нельзя отменить  │
│                                │
│  [Отмена]      [Удалить]       │
└────────────────────────────────┘
```

## API Integration

### Используемые endpoints:
- `GET /api/history` - получить всю историю
- `GET /api/history/recent` - последние 10 записей
- `DELETE /api/history` - очистить историю
- `DELETE /api/history/{id}` - удалить запись

### Данные записи:
```json
{
  "id": 123,
  "operation": "ADD",
  "operandA": 5.0,
  "operandB": 3.0,
  "result": 8.0,
  "expression": "5 + 3 = 8",
  "timestamp": "2024-01-15T14:32:00"
}
```
