# Экран "Настройки"

## Описание
Экран настроек позволяет пользователю изменять язык интерфейса, тему оформления и точность вычислений.

├─────────────────────────────────────────────┤
│                                             │

│  ┌──────────┐  ┌──────────┐                │
│  │ English  │  │ Русский  │ ← выбран       │

## Компоненты

### 1. Header (Шапка)
- **Кнопка "Назад"**: возврат на главный экран
- **Заголовок**: "Настройки" / "Settings"

### 2. Language Selector (Выбор языка)
- Иконка: 🌐
- Заголовок секции
- Две кнопки-переключатели:
  - English
  - Русский
- Активная кнопка подсвечена

### 3. Theme Selector (Выбор темы)
- Иконка: 🎨
- Заголовок секции
- Две кнопки-переключатели:
  - ☀️ Light (Светлая)
  - 🌙 Dark (Темная)
- Активная кнопка подсвечена

### 4. Precision Slider (Точность)
- Иконка: 🔢
- Заголовок секции
- Описание: "Количество знаков после запятой"
- Слайдер от 0 до 10
- Текущее значение отображается под слайдером
- Preview: показывает пример числа с выбранной точностью

### 5. Info Section (Информация)
- Иконка: 📊
- Версия приложения
- Статус подключения к API
- Session ID (для отладки)

### 6. Save Button (Кнопка сохранения)
- Кнопка "Сохранить изменения"
- Disabled если нет изменений
- Показывает feedback после сохранения

## Интерактивность

### Действия пользователя:
1. **Выбор языка** → Мгновенное применение (интерфейс переводится)
2. **Выбор темы** → Мгновенное применение (меняется цветовая схема)
3. **Изменение точности** → Preview обновляется в реальном времени
4. **Клик "Сохранить"** → Отправка настроек на backend + уведомление

### Feedback после сохранения:
```
┌────────────────────────────────┐
│  ✓ Настройки сохранены         │
└────────────────────────────────┘
```
(Автоматически исчезает через 3 секунды)

## API Integration

### Используемые endpoints:
- `GET /api/settings` - получить настройки
- `PUT /api/settings` - обновить настройки

### Структура данных:
```json
{
  "language": "ru",
  "theme": "dark",
  "precision": 2
}
```

### Валидация:
- language: "en" | "ru"
- theme: "light" | "dark"
- precision: 0-10 (integer)

## Локальные ресурсы vs API

### Из API:
- ✅ Получение настроек пользователя
- ✅ Сохранение настроек

### Из локальных ресурсов:
- ✅ Переводы интерфейса
- ✅ Список доступных языков
- ✅ Список доступных тем
- ✅ Применение темы (CSS)
- ✅ Кэш настроек в localStorage

### Синхронизация:
```
localStorage → React State → API
     ↑                           ↓
     └───────────────────────────┘
```

## Темная тема

### CSS Variables:
```css
/* Light Theme */
--bg-primary: #ffffff;
--bg-secondary: #f5f5f5;
--text-primary: #333333;
--text-secondary: #757575;
--accent: #2196F3;

/* Dark Theme */
--bg-primary: #1e1e1e;
--bg-secondary: #2d2d2d;
--text-primary: #ffffff;
--text-secondary: #b0b0b0;
--accent: #64B5F6;
```

### Переключение:
```javascript
document.body.classList.toggle('dark-theme');
```
